# LLM 多智能体策略与智能体分析台

平台集成了来自 EasyQuant 的多智能体决策框架（`trading_agents` 包），对单只股票运行
一条 LLM 决策流水线：

```text
4 位分析师（基本面 / 情绪 / 新闻 / 技术）
→ 多空辩论
→ Trader 提案
→ 风控评估
→ 组合经理审批（最终决策）
```

本文档说明回测策略插件 `llm_multi_agent` 和网页"智能体分析台"的用法与注意事项。
所有功能仅供研究，不构成投资建议。

## 策略插件 llm_multi_agent

内置策略 `llm_multi_agent`（显示名"LLM 多智能体决策"）与其他策略一样被自动发现，
可在"单次回测与复盘"中选择并调参。每个调仓日，策略先按最近 20 日平均成交额做
流动性预筛，再对候选标的逐个调用决策流水线，把批准的买入决策映射为带显式目标
权重的信号。

### 策略参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `llm_provider` | `mock` | mock 离线确定；openai/deepseek/qwen/glm/ollama 需配置 API Key |
| `debate_rounds` | `1` | 多空辩论轮数（0–4），越多越慢越贵 |
| `lookback_days` | `60` | 喂给智能体的日线窗口长度（20–250） |
| `max_candidates` | `10` | 成交额预筛后的候选标的数量上限（1–50） |
| `max_weight_per_stock` | `0.2` | 单个标的的目标仓位占组合比例上限 |
| `use_cache` | `True` | 缓存 LLM 决策到磁盘，重复回测不重复调用 |

### 决策缓存

`AgentRunner` 把每个"标的 × 调仓日"的最终决策缓存在 `runtime/agent_cache/`（JSON
文件，键含 provider、辩论轮数和行情末日期摘要）。重复回测或同一标的重复分析时
直接命中缓存，不再调用 LLM。删除该目录即可强制重新生成。

### 可复现性

- `mock` provider 完全离线、确定：相同输入永远得到相同结果，可用于回归测试；
- 真实 LLM provider 的结果随采样变化，不可精确复现；开启缓存可以让同一次研究
  内的重复回测保持一致。

### 成本提醒

回测的 LLM 调用次数 ≈ 调仓日数 × 每日候选标的数 ×（4 份报告 + 辩论轮数 × 2 +
提案 + 风控 + 审批）。使用真实 LLM 前请：

1. 先用小股票池、低 `max_candidates`、少调仓频率试跑；
2. 保持 `use_cache: True`；
3. 先用 `mock` 验证流程，再切换真实 provider。

### 环境变量（API Key）

| Provider | 环境变量 |
|---|---|
| kimi | `KIMI_API_KEY` |
| openai | `OPENAI_API_KEY` |
| deepseek | `DEEPSEEK_API_KEY` |
| qwen | `DASHSCOPE_API_KEY` |
| glm | `ZHIPUAI_API_KEY` |
| ollama | 无需 Key（本地服务） |

### 只做多 / T+1 语义映射

平台回测执行层只支持买入目标权重信号、T+1 开盘成交，决策按以下方式映射：

- `approved` + `buy` → 生成目标权重信号（权重取 `final_position_pct`，
  上限 `max_weight_per_stock`），T+1 开盘模拟成交；
- `hold`、`rejected`、`conditional` 非买入决策 → 不产生信号（不建仓）；
- `sell` 及 Trader 提案中的止损价 / 目标价 **不进入执行层**，仅作为研究展示。

## 智能体分析台（网页）

侧边栏"研究与回测"分组中的"智能体分析台"页面对单只股票运行完整流水线并展示
全部中间产物：

- 输入：股票代码、分析日期、LLM provider、辩论轮数（0–4）、回看天数（默认 60）、
  是否使用缓存；
- 点击"运行分析"后，从本地 Parquet 行情取截至分析日期的日线并运行流水线；
- 结果顶部为组合经理决策卡片（审批状态 / 最终动作 / 目标仓位 / 拒绝原因 /
  理由链），下方分栏展开 4 份分析师报告、多空辩论全文、Trader 提案
  （含止损价与目标价）和风控评估；
- 勾选"使用缓存"时优先读磁盘缓存：命中则只展示最终决策，未命中则运行完整
  流水线并写入缓存；取消勾选可强制重跑并查看全部中间产物。

页面展示的止损价、目标价仅供研究参考，不进入平台回测执行层。
