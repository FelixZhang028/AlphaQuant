# FellowQuant 软件使用文档

FellowQuant 是一个本地运行的 A 股日频研究与回测平台，覆盖「数据更新 → 策略信号 → 组合 → 模拟订单 → T+1 成交 → 账户净值 → 绩效分析 → 网页展示」的完整链路，并内置 LLM 多智能体分析台。当前只用于研究与模拟，不连接真实券商，不构成投资建议。

## 1. 安装与启动

1. 安装 Python 3.11 或 3.12（安装时勾选 "Add Python to PATH"）。
2. 双击项目根目录 `install_and_start.bat` 完成首次安装并自动打开浏览器。
3. 之后双击 `start.bat` 即可启动。

命令行方式：

```powershell
python -m streamlit run src/quant_platform/web/app.py
```

## 3. 功能详解

### 3.1 首次使用

首次启动自动进入「开始使用」页，按提示依次完成：股票池配置 → 数据更新 → 回测条件自检。检查通过后即可进入「单次回测与复盘」。

### 3.2 数据管理

- 选择日期范围，更新证券主表、股票池行情、基准行情。
- 可指定本次更新首选数据源（iFinD / AkShare / BaoStock 等）及是否允许自动回退。
- 查看覆盖率报告，按股票与日期筛选、预览并下载日线 CSV。

### 3.3 股票池管理

输入六位代码（支持 `600519.SH`、`SH600519` 等格式），系统自动识别交易所；按名称搜索、移除股票、调整过滤条件（是否排除 ST/停牌、最少上市天数、最少历史天数、最低成交额）。

### 3.4 零代码策略工作台（新手）

- **模板快速回测**：六种模板（动量/均线趋势/低波动/突破新高/均值回归/多周期趋势）× 保守/均衡/激进三档预设，填参数即回测。
- **积木创建策略**：用「全部满足/任意满足」+ 白名单指标 + 判断条件 + 排序/持股数/调仓频率，拼出策略，保存后可复用。
- 该模式不运行用户 Python 代码，安全可控。

### 3.5 自定义策略（Python，进阶）

继承 `BaseStrategy` 并注册，平台按 `__init__` 签名自动生成参数表单。两种入口：

- **编写策略**：在代码编辑器中编写（含起始模板），填写显示名后注册并保存。
- **上传文件**：上传写好的 `.py`。
- **我的策略**：列出已保存策略，调参后直接回测，可删除。

```python
from quant_platform.user_strategies import BaseStrategy, register_strategy

@register_strategy("my_ma_momentum", display_name="我的双均线动量")
class MyStrategy(BaseStrategy):
    def __init__(self, fast: int = 5, slow: int = 20):
        self.fast, self.slow = fast, slow

    def generate_signals(self, context):
        ...  # 返回 list[Signal]，score 越大越优先入选
        return signals
```

详细说明见 `docs/custom_strategy.md`。

### 3.6 单次回测与复盘

选择策略（含内置、零代码、自定义）、调整参数、日期区间、初始资金、持股数量、调仓频率，运行后查看：收益与风险、交易与成本、持仓分析、订单明细。顶部会显示「有效/有警告/无效」可信度结论。

### 3.7 参数优化与稳健性验证

- **网格优化**：对多组参数批量回测（最多 100 组），按收益/Sharpe/Calmar/回撤排序。
- **滚动样本外验证**：滚动训练窗口选参，只在后续未见的样本外区间评价，规避过拟合。

### 3.8 回测记录库

筛选、追溯并对比 2～5 次历史回测的指标与标准化净值曲线。

### 3.9 风险管理

配置总仓位、单股权重、持股数量、现金比例、回撤停止线；每日检查实际持仓漂移，回撤触线后可停止开仓/降仓/清仓。

### 3.10 模拟交易

创建本地日线模拟账户，按指定日期推进（历史日线回放，非实时撮合）。

### 3.11 智能体分析台

对单只股票运行「分析师团队 → 多空辩论 → 交易员提案 → 风控 → 组合经理审批」的 LLM 多智能体流水线。

**① 模型与 API 配置**

- 选择 LLM Provider（Mock / OpenAI / DeepSeek / Kimi / 通义千问 / 智谱 GLM / Ollama / 自定义）。
- 点「配置 …」弹窗填写 Base URL、API Key、模型；**API Key 仅保存在本地** `runtime/llm_settings.json`（不入库），留空则回退到对应环境变量。
- DeepSeek / Kimi 等支持按官方模型名下拉选择（如 `deepseek-v4-pro`、`kimi-k2.6`）。

**② 数据来源**

- 股票行情来源：本地行情（Parquet，离线）/ 东方财富（实时）/ yfinance（美股）。
- 新闻来源（可多选）：东方财富个股新闻 / 财联社电报 / 东方财富全球快讯；勾选「全选」或选择多个来源会提示**耗时增加**。新闻抓取失败自动降级为空，不影响行情分析。

**③ 专家先验知识**

把你自己或网上的观点作为先验知识加入（内容 + 来源），各方向 AI Agent 分析时会优先参考，让 AI 不再只凭行情数据做机械化判断。条目保存在本地，可增删。

**④ 人为介入（与 AI 对话交锋）**

勾选后，分析完成会出现对话区：输入你的观点或质疑，AI 带完整分析上下文回应（同意/反驳/修正立场），可来回交锋，也可选择相信 AI。

## 4. 数据字段说明

策略常用行情字段：`symbol`（标准代码）、`trade_date`、`raw_open/raw_high/raw_low/raw_close`（未复权）、`adjusted_close`（前复权）、`adj_factor`、`volume`（股）、`amount`（元）、`is_suspended`、`is_st`、`up_limit/down_limit`（涨跌停）、`quality_status`。

## 5. 常见问题

- **回测提示「数据不足」**：先到「数据管理」更新对应区间的行情，并确认「股票池管理」已加入该股票。
- **回测被标记「无效/有警告」**：多为区间存在未知交易状态或时间轴断档，缩短区间或补齐数据后再跑。
- **智能体分析台提示未配置 API Key**：点「配置」填写，或设置对应环境变量（`DEEPSEEK_API_KEY`、`KIMI_API_KEY` 等）。
- **新闻来源为空**：新闻是增强输入，抓取失败自动降级；检查网络，或改用本地行情 + Mock 离线验证流程。
