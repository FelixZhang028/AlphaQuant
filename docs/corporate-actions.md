# 回测除权处理

账户按真实股数和未复权价格估值、成交。复权因子仅供研究及检查，不能乘到卖出款上。

本地行情仓储新增 `corporate_actions` 表，使用 `repository.save_table` 写入，
同一股票、同一除权日的现金和送转信息必须合并为一行：

| 字段 | 含义 |
| --- | --- |
| symbol | 股票代码，如 000001.SZ |
| ex_date | 除权日，必须为回测交易日 |
| cash_per_share | 每股旧股应得现金，须已扣除本次建模的税费；无分红填 0 |
| share_multiplier | 除权后股数 / 原股数：不送转填 1，10送10 填 2 |
| pay_date | 现金到账日；未填表示明确采用除权日到账的简化假设 |
| share_listing_date | 新增股份可卖日期；未填表示明确采用除权日上市的简化假设 |

事件在除权日开盘成交前处理，权利归属按上一交易日收盘持仓计算。
现金未到账前计入应收分红和净值，但不能买入；新增股份未上市前计入持仓市值，
但不能卖出。同日新买入的股票不获得本次权益。复权因子变化而缺少事件记录时，
持仓回测报 `MISSING_CORPORATE_ACTION` 并停止，不猜测分红金额或送转比例。

例：1000 股成本 10 元，每股分红 1 元，后来以 18 元全部卖出：
收回现金为 1000 + 18000 = 19000 元，未计交易费的收益为 9000 元。
10送10 后则持有 2000 股；以 5 元卖出 1000 股，只收到 5000 元且仍剩 1000 股。

闭合交易报告单列 `dividend_income`，买入批次成本按送转股数摊薄，卖价保留真实成交价。
回测结果保存本次使用的 `corporate_actions.parquet`，净值记录包含 `dividend_receivable`。

当前行情下载器尚未自动填充该表。真实历史回测须补齐准确的权益记录及日期。
不支持配股缴款、缩股及零碎股结算；不支持的股数变动应显式报错，不能按复权因子模拟。
动态红利税尚未建模，税费应由输入现金权益明确约定。
