# 工作区入口与功能位置

本次调整使用 Streamlit 原生页面、卡片、折叠区和搜索入口，最低版本为 1.63。
业务计算、数据检查、回测确认及可信度审计规则继续沿用原实现。

| 主入口 | 内容 |
| --- | --- |
| 首页 | 验证策略想法、检查外部策略、查看研究结果；继续最近回测 |
| 策略研究 | AI研究员、选股想法、自然语言策略、可视化搭建、Python 策略、回测、优化与稳健性验证、因子、先验知识 |
| 我的研究 | 历史记录、筛选对比与导出、方案复用、平台审计与外部材料核查；继续 AI 研究入口 |
| 数据与运行 | 行情更新、全市场回填、任务记录、数据资产、XTick、股票池、风险规则与记录 |
| 设置 | 模型与数据源配置；个人中心、使用指南 |

每页顶部保留“全部工具”搜索，旧页面路径继续注册；子页面提供返回所属工作区的入口。
AI研究员继续提供单只股票的多代理分析，原有讨论、证据与模拟成交功能仍在原页面。
自然语言策略创建保留独立入口，不将其描述为 AI研究员已经具备的能力。

回测首先显示策略、日期、资金；原有参数、组合分配、股票池口径等放入“高级设置”。
提交后仍须检查数据并确认运行。折叠不会改变参数取值。

结果页展示通俗结论、累计收益、最大回撤、可信度评级与策略/基准走势。
曲线按各自在同一起始日期的权益归一化；缺少基准时明确提示，不补造数据。
完整有效性报告、专业指标、诊断、订单和持仓均可展开。
“查看完整可信度审计”带入当前运行，参数搜索偏差和 DSR 审计继续保留。

验证：`tests/unit/test_workspace_navigation.py` 覆盖五个工作区、工具搜索、外部材料入口、
高级参数提交、历史结果与对应审计跳转；已有首页、账号、引导研究、结果解读和 DSR 测试继续运行。
