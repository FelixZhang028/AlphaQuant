# 零代码策略工作台

“零代码策略工作台”同时提供面向新手的模板快速回测（P0）和积木式策略编辑器（P1）。两种入口最终生成同一份版本化结构化规则，并由通用规则策略解释执行，不会运行用户输入的 Python 代码。

## 模板快速回测

内置六个模板：动量选股、均线趋势、低波动、突破新高、均值回归和多周期趋势。每个模板提供保守、均衡、激进三档预设。普通用户只需选择模板、风格、回测区间、资金、持股数量和调仓频率；策略特有周期与阈值放在默认折叠的“高级设置”中。

运行前，页面会用自然语言说明选股、排序、持仓和退出规则，并提示历史数据长度、集中持仓及高频调仓风险。

## 积木式策略

积木编辑器支持：

- 全部满足或任意满足；
- 收盘价、区间收益、均线、波动率、平均成交额、前期高低点、RSI和区间回撤；
- 大于、大于等于、小于和小于等于；
- 与固定数值或另一个指标比较；
- 选择排序指标、方向、持股数量和调仓频率；
- 策略预览、检查、保存、复制和回测。

条件失效的股票会在下一个调仓日退出。成交仍由平台原有的次日开盘、涨跌停、停牌、费用、滑点和风控规则处理。

## 当前边界

- 普通界面最多六条条件，底层协议最多十条；
- 只使用“股票池管理”中的当前固定股票池；
- 指数历史成分股、行业历史成员和盘中止损尚未纳入本阶段；
- 所有指标严格读取调仓日及以前的数据；
- 策略配置随回测快照保存，已保存的积木策略位于 `runtime/strategy_definitions`。
