# 参数搜索偏差审计

参数优化完成后，结果表增加「DSR 显著性」「参数搜索审计」「参数搜索审计说明」。
原始 Sharpe、优化目标与排序保持原口径。可信度审计新增第六维「参数搜索偏差」，
通过 `parent_experiment_id` 关联 `optimizations/<实验编号>/request.json` 和 `results.csv`。
旧实验只要保存了完整记录和各次回测净值，也可在页面读取时计算。

## 计算范围与口径

- 只覆盖同一批已记录的参数搜索，不包括之前的实验、基准选取或未记录的人工尝试。
- 使用全部可计算试验，包括未满足回撤约束的结果；不只使用排名靠前或符合约束的候选。
- 净值日期、收益频率和无风险利率必须一致；重新计算的 Sharpe 必须与持久化汇总一致。
- 使用日收益超额收益的非年化 Sharpe、样本偏度与 Pearson 峰度（正态为 3）；
  结果面板中的 Sharpe 和选择门槛换算为年化口径。
- 按 Bailey 与 López de Prado（2014）公式 2 计算 DSR。DSR 是统计显著性概率，
  不表示一个新的 Sharpe 数值，也不表示策略未来盈利的概率。
- 按论文附录 3 的平均相关性近似估计独立试验数：
  `N ≈ ρ + (1 − ρ) × M`，其中 M 是本批尝试数，ρ 是试验收益的平均两两相关性。
  实现将 ρ 限制在 `[0, 1]` 并将 N 向上取整；这是近似值。
- 计算要求至少 30 个收益观测且观测数大于试验数。这是产品的估计质量门槛，
  并非论文给出的充分有效性保证。
- 未对收益的时序相关性作修正。一阶自相关绝对值超过 `1.96 / √T` 时，
  附加近似性警告；这一筛查不能排除更高阶依赖。

## 界面和评级

审计面板显示本批尝试数、可计算试验数、估计独立试验数和 DSR。
展开后可查看未校正显著性 PSR、校正门槛、最佳与中位 Sharpe 的差距及逐次证据。
优化页首行面板对应当前目标排名第一的结果；选择其他组合可查看该组合的 DSR 说明。
DSR 只检验 Sharpe 的证据强度，不直接检验其他优化目标。

| 状态 | 条件 | 评级处理 |
| --- | --- | --- |
| 通过 | DSR ≥ 95%，且未检出上述一阶自相关 | 不新增警告 |
| 警告 | DSR < 95%，或检出上述一阶自相关 | 新增一条警告 |
| 无法评估 | 记录缺失、失败、净值无效、口径不同或观测不足 | 不显示概率，新增一条警告 |
| 不适用 | 有完整批次清单证明只尝试一次；或本记录为滚动样本外测试 | 不计通过，不新增警告 |

普通单次回测没有搜索记录时为「无法评估」，不能据此推断历史只尝试了一次。
同批有失败或不可计算记录时，整批均不输出 DSR，避免删除缺失试验后低估选择偏差。
已确认的单次尝试无多重试验惩罚，也不因此宣称收益显著。

总评沿用现有规则：错误级问题为 D；累计至少两条警告为 C；一条警告为 B；
无警告为 A。DSR 不改变原始绩效指标或引擎的 `metrics_reliable` 标记。
页面读取缓存最多保留 30 秒；修改或补齐实验文件后需等待缓存到期。

参考：[Bailey & López de Prado, The Deflated Sharpe Ratio (2014)](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)。
