# 因子库

在「因子实验室 → 因子库」中按名称、编号、公式搜索，并分别筛选投资逻辑类别和来源库。
列表仅展示已注册的实现。选择详情可查看公式、数据字段、最小历史、方向和版本，
点击「用于因子评估」或「加入因子组合」后，切换对应标签继续操作。
筛选不改变评估或组合的股票池。

这批公式使用未复权 OHLC、原始成交量，跨除权日的价格变化可能影响结果。
截面 rank 为输入股票池内的平均百分位排名，常量序列的相关性保留为缺失。
新增公共 rank 按当日最大绝对值归一化后保留 12 位小数，避免浮点计算使理论并列值错排；
新增标准差和协方差使用样本口径（ddof=1）。returns 使用原始收盘价的日收益，缺失不前填。
全窗口有效才输出滚动结果；条件判断所需历史不足时不默认返回 0 或进入另一分支。
零分母、非正成交量的对数和无定义相关系数保留缺失；#023 条件不成立时的 0 是原公式输出。
#006 的常量窗口判断和相关系数数值边界已加强，版本为 1.0.1；其余原有公式未改动。
公式窗口固定，最小历史指每只股票的观测条数，不等于回测日期长度。
实际字段完整性及历史长度在计算时核验；“已接入”不表示数据充分或因子有效。

有效性须在现有因子评估页指定区间和持有期验证，组合后的交易成本、成交限制
继续通过策略回测检验。此次不改变评估、组合和自定义因子的核心流程。

验证包括独立 NumPy/SciPy 公式对照、全部 20 个因子的最小历史及因果性测试、
常量/零值/缺失样本边界测试，以及因子库筛选和评估页面交互。公式可计算不表示在 A 股有效。
