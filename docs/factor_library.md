# 分类与研究意图

因子库使用独立的研究展示分类（`factors/taxonomy.py`），不改变计算公式、交易方向、计算版本或旧注册表的类别字段。

- 当前 82 个 Alpha101 与 10 个内置因子均有明确主类别、研究意图和归类依据。
- 主类别按公式结构区分：动量与趋势、反转与偏离、K线与价格位置、波动与风险、成交与流动性、量价关系、复合信号。自定义算子另支持基础行情特征，未知算子保留未分类。
- 研究意图支持多选，匹配任一选中方向；不选表示全部，再与类别、来源、关键词取交集。表格展示标签，点击行后可查看分类依据。
- Alpha101 逐项显式登记，不按名称或字段猜测。量价相关不直接归为关注放量，包含波动统计的复合公式不直接归为偏好低波动；条件切换和多项混合公式保留复合信号类别。
- “寻找短期超跌”等标签表示可研究的方向，不构成买入条件或有效性结论。自定义因子依据算子归类，仍需检查字段与方向。
- 新增 Alpha101 必须补充分类；覆盖测试会检查已接入编号与分类登记一致。尚未审核的新公式显示未分类，不继承其他因子的标签。
