# 第五步：React 网页与接口联调

日期：2026-10-08。范围：搭建可运行的网页并接入现有 Python 服务；第六步仍需按 125 项清单逐项对照验收，第七步再正式切换。

## 启动

- 日常使用：项目根目录双击 `start_react.bat`，服务就绪后打开 `http://127.0.0.1:8000/app`。
- 当前已安装依赖并生成 `frontend/dist`。其他机器或更新源码后运行 `install_react.bat`，需要 Python 和 Node.js。
- 脚本优先使用项目 `.venv`；其中没有 API 依赖时，启动脚本尝试已具备依赖的系统 Python。安装脚本把 API 依赖安装到 `.venv`（如存在）。
- 命令行：`python -m quant_platform.api.cli --web`。可选 `--port 8002`，可选 `--open-browser`。
- 原 `start.bat` 和所有 Streamlit 页面源码保留。此次没有更改默认入口或自动发布网站。

开发模式：项目根目录启动 `python -m quant_platform.api.cli`，另一个终端在 `frontend` 运行 `npm run dev`。访问 `http://127.0.0.1:5173/app`。

## 关键行为

- 草稿与已检查方案分开；编辑草稿不会偷偷修改待执行参数，运行前仍由后端重新检查。
- 提交前保存幂等键；刷新时可恢复正在提交或已受理任务，后台计算独立于浏览器生命周期。
- 策略、费用、股票池、风险等实际执行配置随研究方案版本保存；引导式方案恢复到想法页，专业方案恢复到回测页。
- 修正研究计划关联主键：一个历史回测可以被多个方案复用。旧表首次打开时在事务内迁移，保留原关联和账号归属；有专门的旧表迁移测试。
- 曲线缺失值不填零、不跨缺失点连线。基准须与策略使用相同首日归一化。
- 所有完整表格支持分页或完整 CSV；图表净值与基准数据分批读完整，不把前 5000 条冒充完整区间。
- 风控统计取最近 10 次成功回测的完整事件，预览分页不影响计数。
- 浏览器不回填已保存密钥；凭证由后端保存在原运行目录。空白值默认保留，清除须明确勾选。
