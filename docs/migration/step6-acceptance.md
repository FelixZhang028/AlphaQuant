# 第六步功能验收

基线：125 项功能，见 `feature-register.json`。本步核对前端操作、API 与原 Python 服务；发现差异后补实现及回归测试。

## 状态规则

- 通过：具有明确输入、实际运行结果和可复现测试证据。
- 部分通过：主体已验证，但仍有未覆盖的子条件。
- 延后：按用户约定暂不接入登录；旧入口兼容随第七步切换。
- 保留原状态：旧版禁用占位和休眠代码。
- 未通过：存在真实差异，需修复后重验。

不会把页面可打开、源码存在或单一成功样例当作整项功能通过。真实付费模型和行情接口不自动调用；先用固定返回核对成功、失败及降级，再单独记录本机实际连接情况。

## 执行范围

1. 复核全部 125 项，标注登录、占位和切换例外。
2. 运行原 `.venv` 中的单元回归和迁移 API 回归。
3. 补齐同输入的全部指标、逐日净值、成交/费用/持仓明细和完整 CSV 对照。
4. 扩展浏览器验证：上下文跳转、草稿、历史实验、组合失效、异常反馈及窄屏。
5. 修复差异，更新逐项证据与剩余边界。

### 数值核对

- 使用隔离样例仓库：4 只证券、2022—2023 年行情；以同输入分别执行 Python 服务和 HTTP 回测。
- 核对全部原始 summary 字段、validity，以及净值、信号、目标仓位、订单、成交、完整交易、持仓、风险事件、公司行为共9类明细；保留行列、日期、缺值、状态与费用口径。
- 浮点使用绝对 `1e-12` 容差、相对容差为0；代码、交易日期、状态、行数与排序精确比对。
- 两次运行的随机订单/成交 ID 使用一一对应关系，验证订单、成交和完整交易之间的链接。生成/成交的系统时间不要求跨运行相等，但同次运行的接口字段与磁盘结果逐项核对。
- 9类 CSV 与本次磁盘完整结果逐列比对，中文 BOM、全部行与空表处理均有断言。浏览器另验证超过200行预览的行情下载完整。
- 策略与基准按同一首日归一化；基准中途缺值保留空值，首日缺失则不从另一日起算；没有行情的月份不补成零收益。

### 本轮修复

1. 显式重新检查失败时，清除旧的已核对请求及确认状态；数据补齐后的自动重查和重查已提交方案使用同一规则。
2. 回测结果展示实际提交参数；草稿已修改时明确标记旧结果，避免误当本次策略结果。
3. 加固草稿、任务及待恢复提交按作用域隔离；资源切换时清除旧数据，忽略已中止请求的迟到响应。
4. 参数优化完成后自动刷新历史列表。历史记录、持久任务结果和CSV下载重新核对搜索证据；子净值缺失时撤销旧DSR概率，并保留原目标排名。返回完整DSR依据和试验清单。
5. XTick的ZIP与普通JSON统一检查远端错误码；失败的新查询清除旧结果和旧接口历史引用，刷新后也不会重新显示旧成功结果。
6. 自然语言策略重新生成或填入示例时清除旧确认和“已保存”状态；放弃不注册，失败不展示旧草稿。
7. Python初始模板晚到时不会覆盖用户已输入的代码；测试通过刻意延后模板响应复现这一情况。
8. 补回回测页四个研究阶段入口。记录筛选取全部历史中的实际运行类型，保留未知历史类型，不硬编码不存在的训练类型。
9. 补齐股票池更新主表、修改后补行情的引导，以及欢迎页英文就绪检查按钮。

### 第二轮补充验收

- 新增12个API参数化用例与4个浏览器用例。原573项单元回归沿用首轮结果；本轮未改原计算服务。
- 外部材料：核对股/手换算、未复权价格确认、含空行的原表行号、缺失证券证据、全部发现与Markdown报告逐字段保持原服务输出；错误行返回422，不静默丢弃。
- 浏览器实际执行重复行拒绝及确认、更换文件/数量单位后撤销确认、映射修改后撤销报告；按结论筛选后下载的文件逐字等于未筛选完整报告。
- 使用受控延迟响应，验证修改材料后，旧预览与旧核查报告均不会回写；修复文件上传沿用旧预览及材料变更沿用旧重复确认。
- 回填：八种状态逐项核对，只有PARTIAL/FAILED/STOPPED/INTERRUPTED可以继续，沿用原日期与数据集；浏览器验证活动任务阻止继续另一条回填。
- 修复回填选中任务刷新后丢失，以及活动任务存在时仍可点击历史任务继续的按钮。请求停止后仍显示运行中的任务，按钮禁用，直到状态真正变为STOPPED；日志和选择可在刷新后恢复。
- 新增通过项：EXT-02、EXT-03、EXT-04、JOB-02。共47项通过、68项部分通过、7项延后、3项保留原状态。其余条目仍保留原标准，未自动签收。
- 回填浏览器验证使用固定响应；接口状态测试替换进程启动方法。未触发真实全市场回填、行情下载或供应商调用。

### 第三轮补充验收

- 新增20个API用例、14个浏览器用例，并扩展既有AI跨上下文测试；原573项单元结果沿用首轮，本轮未改原计算服务。
- 数据概览、股票池覆盖明细、CSV及来源状态与原DataCenterService逐字段核对。空行情和读取失败在界面显式提示，可刷新恢复。
- 修复日常更新页没有禁用回填冲突的问题：轮询回填状态，活动回填、读取中或读取失败时禁止提交。服务端保留原互斥检查，处理轮询之间的竞态。
- 检查数据集为空、未知数据集、错误日期和日期倒置不会进入队列；本次来源、回退开关、多个基准代码原样传递，不改默认来源。
- 成功、部分成功、全部失败三种更新任务都保留完整结果且脱敏；浏览器刷新恢复部分失败结果，CSV包含成功项和失败项。
- 修复基准绘图选择未同步表格与CSV的问题。切指数后三者使用同一证券及日期筛选；基准、中文证券主表和版本清单以605行验证服务端分页与完整导出，浏览器另验证跨批次及下载末行。
- 数据版本保留来源、时间、请求路由、实际失败/成功回退路径；错误中的凭证被脱敏，空版本返回空表。
- AI正常流程使用隔离Mock模型；输入和凭证校验在排队前拒绝，证券代码按原规则标准化。本地行情只取分析日期及之前的最后N行，完整先验知识不受列表过滤影响。
- 验证缓存模式只返回最终决策，完整模式保留state；刷新只回放既有任务，不再次提交。重新分析清空上一轮对话。
- 修复AI发送新观点时丢失已完成历史的问题：持久记录本次研究的最后成功对话。提交失败、后台任务失败及刷新后保留历史和未成功观点，后续发送继续使用正确上下文。服务端拒绝未完成分析及跨研究历史。
- 对照旧版补回审计页执行假设与原始有效性证据链。费率、参与率、滑点和未知状态策略只读取历史快照；缺快照标“未记录”，当前配置变化不改历史报告。参与率12.5%、滑点0.123%和成本1.23%分别验证单位。
- 审计界面新增中文评级、通过维度数、绩效可用性、观测数、成本占比，以及六维结论和明细。用A/B/C/D四种固定响应验证通过/警告/失败/无法评估/不适用语义；实际报告与原audit_persisted_run逐字段一致。切换到无结果的运行后清除旧报告。
- 新增通过项：DATA-01/02/03/04/06/07/08、KN-01、AI-01/03/04/07、AUD-01/02/04。当前62项通过、53项部分通过、7项延后、3项保留原状态。
- 外部错误、全量大表和审计评级使用固定响应或隔离样例；没有触发真实行情下载、真实全市场回填或收费模型请求。AI新闻降级、全部中间证据及模拟成交的剩余细节仍保留部分通过。

### 仍需验收的边界

- 部分条目的主体与共享计算已验证，但其余React交互组合、缺数据或服务异常分支尚未全部逐条执行；不因原版单元测试通过就替新界面签收。
- 模型与XTick使用固定响应验证契约，AI使用离线模型完成真实任务流程；未自动调用收费模型或真实行情下载。实际网络、权限、代理和供应商服务状态仍需单独联调。
- 登录、注册、私有账号归属按约定延后；旧URL兼容与默认启动入口属于第七步。旧版休眠/禁用占位保留原状态。
- 本轮没有改写旧Streamlit页面，也没有删除生产行情、历史回测或旧账号数据。

## 复现

首次原版回归因系统 `pytest-of-admin` 临时目录权限不足出现130个setup错误；改用项目内的全新临时目录后，573项全部通过。不要把首次环境错误统计为功能失败。

在项目根目录执行（临时目录每次换一个全新名称）：

```powershell
.venv/Scripts/python.exe -m pytest tests/unit -q -p no:cacheprovider --basetemp=outputs/migration/unit-new --junitxml=outputs/migration/step6-legacy.xml
python -m pytest tests/integration/test_api.py tests/integration/test_background_tasks.py tests/integration/test_workspace_api.py -q -p no:cacheprovider --basetemp=outputs/migration/api-new --junitxml=outputs/migration/step6-api.xml
cd frontend
npm run build
$env:PLAYWRIGHT_JUNIT_OUTPUT_FILE='../outputs/migration/step6-browser.xml'
npm test -- --reporter=list,junit
cd ..
python scripts/build_step6_acceptance.py
```

生成器遇到失败或跳过测试会拒绝输出通过记录。报告按原125项编号关联证据，不改写原始验收标准。
