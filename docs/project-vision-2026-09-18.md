# 量化研究平台：项目定位与路线图

> 版本：2026-09-18 · 供合伙人讨论
> 一句话定位：**不做"更好的回测工具"，做"唯一会告诉你'你的回测哪里在骗你'的平台"。**

---

## 0. 一页纸摘要

- **市场判断**：A 股量化平台十年混战格局已定（聚宽/米筐/掘金/BigQuant/Qlib），正面战场（全市场数据 + 免费增值 + 社区）后来者没有胜算；但存在一个结构性空白——**所有平台都在帮用户"更快上手"，没有人帮用户"看懂自己被什么欺骗"**。
- **核心资产**：平台已建成机构级严谨引擎（防未来函数三重防线、分红送配严格校验、历史税费分期、流动性容量约束，502 项自动化测试全过）——这套"处处怀疑"的工程文化恰好是可信度产品的天性。
- **商业模式**：第一曲线 B2B（5-20 人小私募的内部研究工作台，SaaS/私有化部署，席位收费）；第二曲线轻量 B2C（策略验伪工具，BYOD 自带数据，订阅制）。
- **壁垒**：不是技术单点，而是四项只能靠日历时间积累的复利资产（见第四节）。
- **当前阶段**：数据闭环进行中（分红送配管道已上线并验证）；下一步的关键动作是把已有的审计能力**产品化**为「审计报告」——工作量最小、定位价值最大。
- **最重要的一条纪律**：每个功能决策先问一句——"这个功能在积累四项复利资产中的哪一项？"不积累资产的功能做得再多，平台也不会更难被替代。

## 1. 市场判断：为什么是现在，为什么不是"再做一个聚宽"

### 1.1 三个事实

1. **赛道拥挤且商业化困难**。聚宽、米筐用十年和巨额数据采购费建立壁垒；优矿衰落、果仁网八年卡在小规模。散户付费意愿低、流失快；机构自建或买 Wind/恒生。先驱们的墓志铭已经写好。
2. **这个行业的"产品"其实是数据，不是引擎**。引擎是容器，数据是内容。任何以"更好的引擎"为卖点的定位，都会被"别人也可以写一个引擎"证伪——Qlib 开源且质量不差。
3. **空白地带真实存在**。在聚宽跑出"年化 50%"、实盘却亏损的用户数量巨大，他们的痛点不是"再要一个平台"，而是"**为什么回测和实盘不一致**"。这个人群从未被任何平台服务过——平台们的利益是让用户相信自己的回测有效。

### 1.2 时代变量：AI 改变了两件事

- **交互窗口**：聚宽/米筐是十年前架构 + 补丁式 AI；从零构建 agent-first 工作流（自然语言 → 策略 → 审计 → 回测 → 归因）有机会定义新范式。窗口约 12-24 个月。
- **解释层免费化**：大模型把"把专业内容翻译成人话"变成商品。这对我们有利——解释层直接用商品化 LLM，专注做测量层。

### 1.3 "秤与嘴"：为什么 LLM 是组件而不是对手

把策略粘给豆包/千问/智谱，它们能说出**意见**（概念解释、常见问题清单）；但它们给不出**测量**——没有数据仓库、不执行代码、不承担结果、每次回答不一致。

真实例证：本平台首次真实数据回测时，引擎直接拦截——

```text
BacktestValidityError: MISSING_CORPORATE_ACTION: 600036.SH 2024-07-11
```

（招商银行当日分红导致复权因子变化，引擎拒绝用复权价糊弄现金结算。）

**没有任何一个聊天机器人能发现这个问题**——它不在代码文本里，在数据里。这就是"测量"与"意见"的分界线。

分层结论：

```text
解释层（嘴）→ 用商品化的 LLM，谁便宜用谁
测量层（秤）→ 自建：PIT 数据 + 严格引擎 + 审计规则 + 可复现报告
```

## 3. 战略定位：回测可信度平台

### 3.1 定位陈述

> **"我们是唯一会告诉你'你的回测哪里在骗你'的平台。"**

把审计能力从引擎的内部校验变成**产品主角**：回测不再是"给你一条净值曲线"，而是"给你一份可信度评估 + 证据链"。

### 3.2 结构性中立：incumbents 进不来的位置

- **聚宽/米筐做不了**：它们的商业模式是让用户相信自己的策略能行（卖数据、卖课程）。审计自己的用户 = 既当运动员又当裁判。
- **大模型公司做不了**：没有测量基础设施，且不对数字负责。
- **Qlib 做不了**：它是框架，没有数据语料，没有承担责任的主体。

"中立第三方审计"不是能力门槛，是**立场门槛**——这与第三方评级机构能和投行共存百年的逻辑相同。

### 3.3 反向定位

| 所有人在做（避开） | 空白地带（我们的位置） |
|---|---|
| 帮用户更快上手交易 | 帮用户看懂自己被收割的方式 |
| 生产策略 | 审计策略 |
| AI 荐股 / 炒股助手 | AI 解释风险 |
| 再造一个回测平台 | 告诉你回测结果是假的，并给出证据 |

## 4. 壁垒：四项复利资产

单点技术（引擎代码、因子公式、AI 能力、买来的数据）都不是壁垒——可复制、可购买、或开源是设计意图。真正的壁垒是**只能靠日历时间积累、无法用资本和代码加速**的资产：

| # | 资产 | 本质 | 为什么买不到 |
|---|---|---|---|
| 1 | **PIT 数据语料** | 退市股、历史成分、时点财务、分红送配——验证过且持续维护的数据仓库 | 代码一夜可抄，校准过的秤砣要一天一天攒（每条明细都要核对，如招行每股 1.972 元） |
| 2 | **审计判例库** | 每审计一个策略 = 一个标注样本：造假模式长什么样、如何暴露 | 方法论公开也没用，判例是用户用出来的（类似杀毒病毒库）——唯一的网络效应 |
| 3 | **审计员实绩** | 时间戳在案的实盘对照记录：判死刑的真死了，放行的兑现了 | 只能用日历时间换；今天开始记录的人永远领先今天没开始的人 |
| 4 | **结构性中立** | 被机构采用、被报告引用形成的公信力 | incumbents 结构性进不来（利益冲突），信任无法用钱速成 |

**共同特征：复制成本随时间指数上升。**这就是"壁垒"的本质——不是"别人做不出"，而是"别人重做一遍需要同样的时间，而时间不能压缩"。

诚实说明：这四项今天全是种子（数据语料 9 只股票、判例库为空、实绩记录今天才开始）。**平台没有现成的护城河，但有一个别人没有的挖法**——大部分竞品的壁垒用钱堆，我们的壁垒只能用日子攒。

## 5. 用户与商业模式

### 5.1 第一曲线：B2B 小私募（现金流与产品打磨）

- **目标客群**：5-20 人的小私募。有管理费预算、内部研究基础设施糟糕、决策链短。
- **关键契合**：私募最怕策略泄露，公有云多租户（聚宽模式）满足不了**私有化部署**需求；愿意为"严谨引擎 + 私有部署 + 审计报告"付溢价。
- **形态**：SaaS 或私有化 Docker 部署，按席位收费。
- **验证方式**：10 个付费种子用户即可验证定价假设，不需要融资。

### 5.2 第二曲线：轻量 B2C 验伪工具（获客漏斗顶端，非收入主力）

- **形态**：免费粘贴策略代码/业绩曲线出简版疑点报告 → 订阅解锁深度审计 + AI 解说。
- **成立条件**：BYOD 消解数据成本（用户自带 AkShare/Tushare）；验伪是"分析过去"不构成投资建议（合规上比策略平台离荐股红线更远）；"晒可信度报告"具备社交传播性。
- **顺序逻辑**：B2B 先跑通、审计能力被私募背书后，C 端报告才有公信力。**顺序本身就是战略。**

### 5.3 "小白桥梁"的正确修法

市场判断：量化认知确实早期，但"教小白做量化"有三个经典陷阱——市场大小幻觉（不知道 ≠ 需要）、宿命剧本（小白跑出第一个"年化 50%"必然过拟合 → 实盘亏损 → 卸载）、教育市场只有巨头付得起（教育成果被 i 问财等低门槛产品收割）。

**正确的桥：不通往"做量化"，通往"看懂量化/防身"。**

- AI 翻译官：小白语言解释专业概念；
- 策略验伪：审计别人发的"神策略"；
- 散户行为审计：导入券商交割单，AI 量化行为缺陷（追涨杀跌评分、处置效应）→"韭菜指数"——把审计思维从策略转向人，市面上没有；
- "年化 50% 是怎么伪造的"演示器：让小白亲手调参数、亲眼看垃圾策略如何被调成完美曲线——被骗过一次的体验胜过一百篇科普文。

### 5.4 永不做的（聚焦纪律）

- 传统 B2C 量化平台（全市场数据 + 社区 + 免费增值）——拿融资去填聚宽填过的坑；
- 策略市场、社区功能、课程体系——聚宽的地盘，进去就是消耗战；
- **L3 全自动实盘交易**（见 5.5）。

### 5.5 交易闭环的三层取舍

| 层次 | 内容 | 决策 |
|---|---|---|
| L1 信号跟踪验证 | 策略产出目标持仓 → 实盘行情持续跟踪 → 与回测预测对照 → 偏差归因 | **必做，优先**。它是可信度闭环的收尾：回测（承诺）→ 审计报告（凭什么）→ 实盘跟踪（眼见为实） |
| L2 订单辅助 | 订单文件导出 → 用户自己的 QMT/Ptrade 半自动执行 | 轻做。执行模型的容量约束天然转化为高质量订单指令 |
| L3 全自动交易 | 平台直连券商 API 下单 | **不做**。执行层已被迅投/恒生做穿；牌照红线；与定位无关（价值在"下单之前"，不在"下单之中"） |

一句话：**打通到"让用户看见真相"，不要打通到"替用户扣扳机"。**

## 6. 产品路线图：四大支柱

### 支柱一：可信度产品化（定位核心）

现状问题：有效性审计是全平台最值钱的资产，但目前只是回测报告角落里的两行 WARNING——"把钻石当煤炭用"。

1. **「审计报告」页**（优先级最高，工作量最小）：每次回测自动生成结构化可信度报告——未来函数检查清单、幸存者偏差暴露度、成本假设敏感性（费率 ±50% 业绩变化）、容量测算（最大可承载资金）、样本内外标识，汇总为 A/B/C/D 可信度评级。引擎校验逻辑全部现成，纯产品化封装。
2. **「策略验伪」工作流**（获客钩子，三级入口）：
   - **模式 A（有代码）**：五步管线——LLM 提取策略规格单 → 用户确认（防幻觉 + 审计合同）→ 重述为原生策略 → 严格引擎重跑（PIT 数据/退市股/真实分红/历史税费/容量约束）→ **差异归因报告**（他的年化 50% vs 重跑的 X%，差距逐项分解）。
   - **模式 B（只有结果，杀手锏）**：取证核查——用 PIT 数据对账他的主张：声称某日买入的股票那天一字涨停根本买不进；持仓里出现回测期后才上市的股票；声称低换手但成交记录算出周换手 200%。**每一条都是可证伪的事实，不是观点。**不需要全市场数据即可起步。
   - **模式 C（只有截图/描述）**：NL 重建 + 报告标注"重建策略，非原件"。
   - **工程红线**：不跑别人的代码，重述别人的逻辑。数据 API（读侧）可适配，交易语义（执行侧）必须重述——95% 兼容的适配器对回测平台是小 bug，对审计平台是死刑（秤本身差 5% 就不能称东西）。永远不声称"原样兼容"，只承诺"逻辑等价、经你确认"。
3. **WARNING 升格**：从日志文字变成页面一等公民（红色横幅 + 点击展开解释 + 修复建议）。

### 支柱二：B2B 私募工作台（变现路径）

- 角色与留痕：管理员/研究员/只读 + 操作审计日志（谁在何时改了哪个策略）——私募内控合规刚需；
- 策略评审流：草稿 → 待审 → 已审 → 实盘跟踪，带评审意见；
- 归因增强：现有相对基准指标（IR/回归 Alpha/Beta/跟踪误差）之上，补 Brinson 归因 + 因子贡献归因；
- 一键报告导出（给投资人/风控看的 PDF 格式）；
- 私有化 Docker 部署包。

### 支柱三：AI-native 主线化（超车窗口）

- 对话式研究循环：自然语言贯穿"建策略 → 跑回测 → 看审计 → 改策略"，Agent Lab 从旁挂实验功能升为主线；
- **AI 审计解说员**：LLM 把审计报告翻译成大白话 + 每个疑点给修复建议——把支柱一和支柱三缝合起来的差异化中的差异化；
- AI 对照实验：一键参数敏感性 + 随机基准对照（过拟合检测自动化）。

### 支柱四：BYOD 数据轻资产

- 数据源中心页：token 管理、连通性测试、源间对账（复权因子 vs 分红明细对账报告归这里）；
- "接入你自己的数据"引导式配置——把"不承担数据采购成本"包装成"数据主权在你"的卖点。

### 顺手清理

页面双 8 号编号、重复入口；README 与实现同步；模拟盘保持回放式（L1 升级在路线图中）。

## 8. 风险与合规

| 风险 | 应对 |
|---|---|
| **监管红线**：面向散户的 AI + 投资建议是强监管区 | 所有功能 wording 只指向"分析过去"，不指向"预测未来"。教育可以、验伪可以、**荐股不行** |
| **程序化交易新规**（2024-2025 落地） | 只做 L1 跟踪 + L2 订单导出，不碰 L3 下单；提醒客户报备义务 |
| **免费数据源商用授权** | 内部研究无问题；对外服务前必须解决授权（聚宽/米筐都向数据商付费）。BYOD 模式天然规避：用户用自己的数据源 |
| **云 IP 限流**（东财等对机房 IP 风控） | 退避重试 + 多源冗余（5 provider 架构支持主备） |
| **AI 窗口期**（12-24 个月） | Agent Lab 加重而不是点缀；先发者靠"工作流锁定"守住 |
| **LLM 幻觉**（策略提取错误） | 人肉确认环节兜底——LLM 只当翻译，不当裁判 |

## 9. 关键决策原则（一页备忘）

1. **功能试金石**：这个功能在积累四项复利资产（PIT 数据语料/审计判例/实绩记录/公信力）中的哪一项？不积累的，能外包就外包。
2. **秤与嘴分层**：解释层用商品化 LLM；测量层（数据 + 引擎 + 确定性报告）自己攥。豆包升级只会让解释层更好用，动不了测量层。
3. **不跑别人的代码，重述别人的逻辑**——审计平台的测量精度必须高于被测对象。
4. **B2B 是入场券，B2C 是第二曲线，顺序不能反**——没有机构背书的"可信度"对散户没有公信力。
5. **通往量化常识的桥，不是通往量化工具的桥**——卖止痛药（防割），不卖希望（暴富）。
6. **用日子攒壁垒，不用钱堆壁垒**——四项复利资产每过一天增值一天，早一天埋进产品就早一天开始复利。
