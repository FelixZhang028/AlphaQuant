# 新手研究流程

入口：登录后的首页「验证我的选股想法」，或「策略工作室 → 选股想法」。

1. 选择趋势上涨、短期超跌、低波动，对应 20 日动量、5 日反转、20 日波动率。
2. 从当前配置股票池选择候选股，设置日期、持仓数及调仓频率；资金设置默认折叠。
3. 核对中文规则，确认后检查数据。模板使用去极值、标准化、缺失样本剔除和等权仓位；不修改全局股票池及策略配置。
4. 不足时可更新所选股票和基准（包含预热区间），然后自动复查。更新失败保留本次会话的研究输入，可重试。
5. 通过检查后调用现有回测引擎，结果及实际配置保存到研究记录；点击「查看完整回测报告」进入原有报告。

普通「回测与验证」也增加了提交方案、数据检查、补齐重试和确认运行环节。修改其表单后需重新提交，待运行参数可展开核对。

修改新手规则后，确认、数据检查和结果链接失效；切换页面后草稿仍在本次登录会话中保留。需要跨会话保留时，使用「保存研究方案」。

## 第二阶段

- 回测报告先展示收益相对基准、最大回撤和验证状态的中文解读，专业指标与交易明细折叠展示。缺失指标不推断收益能力，未通过审计会明确提示。
- 方案按账号保存在 `runtime/state/research_plans.sqlite3`（以配置的 runtime_dir 为准）。保存执行配置快照，修改后新增版本；回测自动保存并关联实际执行版本。历史数据文件不复制，因此恢复配置不等于锁定历史数据版本。
- 在「研究记录 → 我的研究方案与版本」恢复方案、打开关联报告、比较配置与已有结果。条件不同会提示不可直接排名；没有运行的版本不展示虚构收益。恢复后需重新检查数据、确认执行，样本外验证需重新开展。
- 因子库增加研究意图标签和通俗关键词；默认不展示详情，点击行查看，可以收起，也可转入评估或组合。意图标签仅帮助发现因子，不是有效性结论。

检查覆盖所选股票、行情字段、区间记录、预热历史、状态和基准数据。检查依据本地交易日历，不能认证数据源本身是否完整；引擎仍执行有效性审计。固定股票池仍可能有选择偏差，模板不代表已经验证的收益能力。更新成功取决于数据源连接与授权，缺少真实数据不会自动用示例数据替代。
