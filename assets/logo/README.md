# FellowQuant Logo · 星轨折线（Starlight Trajectory）

> 2026-08-30 起启用的新品牌符号，取代初版「群智海豚」。
> 设计灵感取自 DeepSeek 的「单一高识别度抽象符号」路线，但视觉语言完全原创。

## 设计寓意

| 概念 | 视觉转译 |
|---|---|
| **Quant · 量化** | 一条向右上攀升的**折线**——净值曲线、趋势与信号 |
| **Fellow · 同行** | 主线下方一条更细的**伴行线**，同向相随——伙伴与协作 |
| **方向与指引** | 折线终点化作一枚**四芒星**——目标是星辰，也是洞察 |
| **独立符号** | 单一几何图形、无文字、无动物形象，小尺寸（16px）仍可辨认 |

## 使用建议

- **favicon / ≤32px**：优先 App 图标版（实底反白，对比度最高）
- **加载动画**：四芒星天然适合做「闪烁 / 脉冲」动效
- **留白规范**：符号四周保留 ≥ 1/4 折线高度的净空；不要旋转、拉伸、改色、加描边
